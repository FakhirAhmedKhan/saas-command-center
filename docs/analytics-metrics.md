# Analytics Metric Definitions

## Visitor

A visitor is one first-party visitor identifier generated by the tracker for one website.

A visitor identifier is unique only inside its website.

## Session

A session is one tracker session identifier.

The tracker creates a new session after 30 minutes of inactivity.

Events received late remain connected to their original session identifier.

## Page view

A page view is a valid `PAGE_VIEW` event after URL normalization.

Repeated views of the same page are counted separately.

## Entry page

The entry page is the earliest page view in a session.

## Exit page

The exit page is the latest page view in a session.

For a one-page session, the same page is both entry and exit.

## Session duration

Session duration is the greater of:

1. Time between the first and last event.
2. Total valid heartbeat duration.

Duration is capped at 24 hours.

## Engaged duration

Engaged duration is the sum of accepted heartbeat durations.

## Bounce

A session is a bounce when all conditions are true:

- It has zero or one page view.
- It has no custom event.
- It has less than 10 seconds of engaged heartbeat duration.

## Source

Source is derived from the first referrer associated with the session.

Source types:

- `DIRECT`
- `INTERNAL`
- `SEARCH`
- `SOCIAL`
- `REFERRAL`
- `UNKNOWN`

## Device

Device type is derived from the user-agent string:

- `DESKTOP`
- `MOBILE`
- `TABLET`
- `BOT`
- `OTHER`

User-agent parsing is approximate and must not be treated as a permanent device identity.

## Country

Country is stored only when a trusted deployment proxy provides an ISO two-letter country code.

The public request must not be trusted to supply this value directly.

## Hourly and daily aggregates

Aggregate boundaries use the website's configured IANA time zone.

The stored bucket timestamps are UTC representations of those local boundaries.

## Unique visitors in aggregates

Visitors are unique within one aggregate bucket.

Unique visitor counts must not be summed across multiple buckets to calculate an exact long-range unique total.

Phase 11 must calculate exact range-level unique visitors from normalized visitor/session data or a dedicated distinct-count strategy.

## Late events

A newly processed late event causes its affected session and hourly/daily buckets to be rebuilt.

## Idempotency

A raw event maps to at most one normalized analytics event.

Rebuilding an aggregate first replaces the existing bucket, so repeated processing does not inflate results.
